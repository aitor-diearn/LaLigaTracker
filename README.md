# LaLigaTracker

Aplicación no oficial de la liga española que genera la clasificación y partidos disputados en la actual temporada. 

Los datos del campeonato son obtenidos a partir de la API <a href="https://www.football-data.org/">football-data.org</a>, y transformados mediante código, guardándose estos en tantos ficheros JSON como sean necesarios. Dichos ficheros JSON se almacenan en la carpeta <i>backend/output</i>.

El proyecto se ha hecho mediante scripts de Python, ejecutados usando un entorno virtual, creado con venv.
